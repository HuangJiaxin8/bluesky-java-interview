### LC0128 最长连续序列-中等

```txt
给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

注意：时间复杂度要求，所以不能用排序
```

```java
public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<Integer>();
        for (Integer num : nums) {
            set.add(num);
        }

        Integer longest = 0;
        // 注意这里遍历的是set，去重减少时间复杂度
        for (Integer num : set) {
            if (!set.contains(num - 1)) {
                Integer currentNum = num;
                // 注意这里是1
                Integer current = 1;

                while (set.contains(currentNum + 1)) {
                    currentNum += 1;
                    current += 1;
                }
                longest = Math.max(longest, current);
            }
        }

        return longest;
    }
```

```java
	ListNode tail = null;

		int i1 = l1 == null ? 0 : l1.val;
		int i2 = l2 == null ? 0 : l2.val;
		int sum = i1 + i2 + carry;
		if (head == null) {
			head = tail = new ListNode(sum % 10);

			tail = tail.next;

			l1 = l1.next;
		}
		if (l2 != null) {
			l2 = l2.next;
		}
	}

		tail.next = new ListNode(carry);
	}
	return head;
```

```java
    if (node == null || node.next == null) {

}
```

### LC0234 回文链表-简单+

https://leetcode.cn/problems/palindrome-linked-list/description/

定义：
* 回文结构的链表指的是链表的节点序列从前往后和从后往前读是相同的。换句话说，链表的节点值以中间节点为对称轴，左右两边是镜像关系。  
* 1 -> 2 -> 3 -> 2 -> 1  

解法：
* 找到链表的中间节点：使用快慢指针法，快指针每次走两步，慢指针每次走一步，当快指针到达链表末尾时，慢指针正好在链表的中间。  
* 反转后半部分链表：从慢指针开始，反转链表的后半部分。  
* 比较前后两部分链表：将前半部分链表和反转后的后半部分链表逐一比较，如果所有节点的值都相同，则链表是回文结构。

```java
public boolean isPalindrome(ListNode head) {  
    if (head == null || head.next == null) {  
        return true;  
    }  
  
    // 1. 找到链表的中间节点  
    ListNode slow = head;  
    ListNode fast = head;  
    while (fast != null && fast.next != null) {  
        slow = slow.next;  
        fast = fast.next.next;  
    }  
  
    // 2. 反转后半部分链表  
    ListNode secondHalf = reverseList(slow);  
  
    // 3. 比较前后两部分链表  
    ListNode p1 = head;  
    ListNode p2 = secondHalf;  
    boolean isPalindrome = true;  
    while (p2 != null) {  
        if (p1.val != p2.val) {  
            isPalindrome = false;  
            break;        
		}  
        p1 = p1.next;  
        p2 = p2.next;  
    }  
  
    // 4. 恢复链表（可选）  
    reverseList(secondHalf);  
  
    return isPalindrome;  
}  
  
// 反转链表  
private ListNode reverseList(ListNode head) {  
    ListNode prev = null;  
    ListNode curr = head;  
    while (curr != null) {  
        ListNode next = curr.next;  
        curr.next = prev;  
        prev = curr;  
        curr = next;  
    }  
    return prev;  
}
```

```java
public static ListNode deleteKthNode(ListNode head, int k) {
        if (head == null || k <= 0) {
            return head;
        }

        // 删除头节点的情况
        if (k == 1) {
            return head.next;
        }

        ListNode current = head;
        // 移动到第k-1个节点
        for (int i = 1; i < k - 1 && current != null; i++) {
            current = current.next;
        }

        // 如果k超出链表长度，直接返回原链表
        if (current == null || current.next == null) {
            return head;
        }

        // 删除第k个节点
        current.next = current.next.next;
        return head;
    }
```

### LC0146 LRU

**解释**
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1

lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4

方法一：用LinkedHashMap，用封装好的api是作弊，最好自己哈希表加双向链表实现一个

```java
class LRUCache extends LinkedHashMap<Integer, Integer> {
    private int capacity;

    public LRUCache(int capacity) {
        // 第三个参数是accessOrder，控制访问顺序还是插入顺序迭代
        super(capacity, 0.75F, true);
        this.capacity = capacity;
    }

    public int get(int key) {
        return super.getOrDefault(key, -1);
    }

    public void put(int key, int value) {
        super.put(key, value);
    }

    // 记住这个方法
    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer,Integer> eldest) {
        return size() > capacity;
    }
}

```

方法二：哈希表+双向链表  （标准答案）

```java
public class LRUCache {
    class DLinkedNode {
        int key;
        int value;
        DLinkedNode prev;
        DLinkedNode next;
        public DLinkedNode() {}
        public DLinkedNode(int _key, int _value) {key = _key; value = _value;}
    }

    private Map<Integer, DLinkedNode> cache = new HashMap<Integer, DLinkedNode>();
    private int size;
    private int capacity;
    private DLinkedNode head, tail;

    public LRUCache(int capacity) {
        this.size = 0;
        this.capacity = capacity;
        // 使用伪头部和伪尾部节点
        head = new DLinkedNode();
        tail = new DLinkedNode();
        // 这个不要忘记了
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            return -1;
        }
        // 如果 key 存在，先通过哈希表定位，再移到头部
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            // 如果 key 不存在，创建一个新的节点
            DLinkedNode newNode = new DLinkedNode(key, value);
            // 添加进哈希表
            cache.put(key, newNode);
            // 添加至双向链表的头部
            addToHead(newNode);
            ++size;
            if (size > capacity) {
                // 如果超出容量，删除双向链表的尾部节点
                DLinkedNode tail = removeTail();
                // 删除哈希表中对应的项
                cache.remove(tail.key);
                --size;
            }
        }
        else {
            // 如果 key 存在，先通过哈希表定位，再修改 value，并移到头部
            node.value = value;
            moveToHead(node);
        }
    }

    private void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(DLinkedNode node) {
        removeNode(node);
        addToHead(node);
    }

    private DLinkedNode removeTail() {
        DLinkedNode res = tail.prev;
        removeNode(res);
        return res;
    }
}
```

### LC0092 反转链表 II

```java
class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 头结点可能会被修改，使用虚拟节点操作
        ListNode dummyNode = new ListNode(0);
        dummyNode.next = head;

        // 找到左节点的前一个节点
        ListNode pre = dummyNode;
        for (int i = 0; i < left - 1; i++) {
            pre = pre.next;
        }

        // 找到右节点 
        ListNode rightNode = pre;
        for(int i =0;i<right-left+1;i++){
            rightNode = rightNode.next;
        }

        // 保存节点
        ListNode leftNode = pre.next;
        ListNode cur = rightNode.next;

        // 反转前要切断链接
        pre.next = null;
        rightNode.next = null;

        // 对leftNode进行反转链表
        reverseLinkedList(leftNode);

        // 重新链接
        pre.next = rightNode;
        leftNode.next = cur;

        return dummyNode.next;
    }

    public void reverseLinkedList(ListNode head){
        ListNode prev = null;
        ListNode curr = head;
        // 这里是curr 不是 curr.next
        while(curr != null){
            ListNode next = curr.next;
```

```java
    queue.offer(t1);  
    queue.offer(t2);  
    while (!queue.isEmpty()) {  
        // 边界值null  
        t1 = queue.poll();  
        t2 = queue.poll();  
        if (t1 == null && t2 == null) {  
            continue;  
        }  
        if (t1 == null || t2 == null || t1.val != t2.val) {  
            return false;  
        }  
  
        queue.offer(t1.left);  
        queue.offer(t2.right);  
  
        queue.offer(t1.right);  
        queue.offer(t2.left);  
    }  
    return true;
```

### LC0046 全排列-中等

https://leetcode.cn/problems/permutations/description

```java
import java.util.*;

class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        // 记录当前路径（正在构建的排列）
        List<Integer> path = new ArrayList<>();
        // 记录元素是否已使用
        boolean[] used = new boolean[nums.length];
        
        backtrack(nums, path, used, result);
        return result;
    }
    
    private void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> result) {
        // 终止条件：路径长度等于数组长度（生成一个完整排列）
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path)); // 注意：需新建列表，避免引用问题
            return;
        }
        
        // 遍历所有元素，尝试加入路径
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue; // 跳过已使用的元素
            
            // 选择当前元素
            path.add(nums[i]);
            used[i] = true;
            
            // 递归处理剩余元素
            backtrack(nums, path, used, result);
            
            // 回溯：撤销选择
            path.remove(path.size()-1);
            used[i] = false;
        }
    }
}
```

### LC0047 全排列II-中等

46题的变种，区别在于数组是否重复

给定一个可包含重复数字的序列 `nums` ，_**按任意顺序**_ 返回所有不重复的全排列。


题解：该题是 “全排列” 问题的进阶版本，可在回溯算法的基础上增加对重复元素的处理来解决。首先对数组进行排序，使相同的数字相邻，然后使用标记数组记录每个位置的数字是否被使用。在回溯过程中，对于重复的数字，只有在前一个数字已经被使用的情况下才能使用当前数字，这样可以避免生成重复的排列。例如，对于数组`[1,1,2]`，在第一个位置选择了第一个`1`后，当在第二个位置再次遇到`1`时，只有第一个`1`已经被使用了，才可以选择第二个`1`，否则会产生重复排列

https://leetcode.cn/problems/permutations-ii/description/

```java
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        // 记录当前路径（正在构建的排列）
        List<Integer> path = new ArrayList<>();
        // 记录元素是否已使用
        boolean[] used = new boolean[nums.length];
        
        // 排序
        Arrays.sort(nums);
        backtrack(nums, path, used, result);
        return result;
    }

    private void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> result) {
        // 终止条件：路径长度等于数组长度（生成一个完整排列）
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path)); // 注意：需新建列表，避免引用问题
            return;
        }
        
        // 遍历所有元素，尝试加入路径
        int lastNum = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (used[i] || lastNum == nums[i]) continue; 
            
            // 选择当前元素
            path.add(nums[i]);
            lastNum = nums[i];
            used[i] = true;
            
            // 递归处理剩余元素
            backtrack(nums, path, used, result);
            
            // 回溯：撤销选择
            path.remove(path.size()-1);
            used[i] = false;
        }
    }
}
```

```java
            }
        };

        backtrack(digits,phoneMap,ans,new StringBuffer(),0);

    }

    public void backtrack(String digits, Map<Character, String> phoneMap, List<String> ans, StringBuffer temp,
            int index) {
        if (index == digits.length()) {
            ans.add(temp.toString());
            return;
        }
        String letter = phoneMap.get(digits.charAt(index));
        for (int i = 0; i < letter.length(); i++) {
            temp.append(letter.charAt(i));
            backtrack(digits, phoneMap, ans, temp, index + 1);
            temp.deleteCharAt(index);
        }
    }
}
```

```java
class Solution {

    public void backtrack(int n, int k, int index, List<Integer> path) {
        if (path.size() == k) {
            ans.add(new ArrayList<Integer>(path));
            return;
        }
        for (int i = index; i <= n; i++) {
            path.add(i);
            backtrack(n, k, i + 1, path);
            path.remove(path.size() - 1);
        }

    }

        backtrack(n, k, 1, new ArrayList<Integer>());

    }
```

### LC0022 括号生成

https://leetcode.cn/problems/generate-parentheses/description

```JAVA
class Solution {
    List<String> ans = new ArrayList<>();

    public List<String> generateParenthesis(int n) {
        if (n <= 0) {
            return ans;
        }
        getParenthesis("", n, n);
        return ans;
    }

    private void getParenthesis(String str, int left, int right) {
        if (left == 0 && right == 0) {
            ans.add(str);
            return;
        }
        if (left == right) {
            //剩余左右括号数相等，下一个只能用左括号
            getParenthesis(str + "(", left - 1, right);
        } else if (left < right) {
            //剩余左括号小于右括号，下一个可以用左括号也可以用右括号
            if (left > 0) {
                getParenthesis(str + "(", left - 1, right);
            }
            getParenthesis(str + ")", left, right - 1);
        }
    }
}
```

```
题目：
整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 旋转，使数组变为 [nums[k], nums[k+1], …, nums[n-1], nums[0], nums[1], …, nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 在下标 3 处经旋转后可能变为 [4,5,6,7,0,1,2] 。

----------------------------------------------------------------------------------

示例：
输入：nums = [4,5,6,7,0,1,2], target = 0  
输出：4

输入：nums = [4,5,6,7,0,1,2], target = 3  
输出：-1

输入：nums = [1], target = 0

----------------------------------------------------------------------------------

提示：

nums 中的每个值都 独一无二  
题目数据保证 nums 在预先未知的某个下标上进行了旋转  
-104 <= target <= 104

进阶：你可以设计一个时间复杂度为 O(log n) 的解决方案吗？
```

**这道题要求时间复杂度为O(log n)。所以不能直接遍历得到答案。**


```java
class Solution {
    public int search(int[] nums, int target) {
        int n=nums.length;
         if (n == 0) {
            return -1;
        }
        if (n == 1) {
            return nums[0] == target ? 0 : -1;
        }

        int l=0;
        int r=n-1;

        while(l<=r){
            int mid=(l+r)/2;
            if(nums[mid]==target)return mid;
            if(nums[0]<=nums[mid]){
                if(nums[0]<=target&&target<nums[mid]){
                    r=mid-1;
                }else l=mid+1;
            }else {
                if(nums[mid]<target&&target<=nums[n-1]){
                    l=mid+1;
                }else r=mid-1;
            }
        
        }
        return -1;

    }
}
```
