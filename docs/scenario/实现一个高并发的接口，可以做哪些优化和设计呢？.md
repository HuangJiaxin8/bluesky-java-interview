缓存+分布式堆机器


缓存：
- 浏览器缓存
- cdn
- 服务器缓存：caffeine + redis
- redis 就采用集群的方式部署

堆机器：
- 数据库
	- 分库分表
	- 读写分离
	- 优化索引
	- 避免慢sql
- 服务器：分布式 + 集群

异步：
- 消息队列，加上可以削峰
- 多线程

批量处理
- 合并请i去，多个io聚合成一个io


提高系统可靠性
- 限流熔断，避免雪崩，
- 监控告警
